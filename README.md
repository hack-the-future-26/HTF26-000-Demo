# 🚀 Hack the Future 26 - GitHub Demo

This repository is used by the organizers to demonstrate the GitHub workflow to hackathon participants.

## 🔄 Demo Workflow

```text
Create Branch
     ↓
Make Changes
     ↓
Commit Changes
     ↓
Create Pull Request
     ↓
Teammate Reviews
     ↓
1 Approval
     ↓
Merge into main
     ↓
Deploy 🚀

🌿 Branches

Do not work directly on main.

Example:

main
  │
  └── feature-demo
🔀 Pull Requests

When your work is ready:

Push or commit your changes to your branch.
Create a Pull Request.
Select main as the base branch.
Ask another teammate to review it.
Get at least 1 approval.
Merge the Pull Request.
🔒 Main Branch

The main branch is protected.

The goal is to keep the team's main project stable and prevent accidental changes.

🧪 Smoke Demo

During the orientation, this repository demonstrates:

Creating a branch
Editing a file through GitHub
Committing changes
Creating a Pull Request
Reviewing changes
Approving a Pull Request
Merging into main
Deploying a simple website
🌐 Deployment

After the code is merged into main, the final project can be deployed using a suitable deployment platform.

For this demonstration, GitHub Pages may be used for the simple website.
